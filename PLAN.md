# ResearchBridge — 5-Day Git Plan

## Day 1: Project Setup + Database
- Initialize project structure
- Set up Prisma schema with Neon
- Create database models (Professor, Institute, ResearchArea, etc.)
- Write import script for Excel data
- Basic Express server setup

## Day 2: Backend API
- Professor endpoints (list, detail, filter, search)
- Institute endpoints (list, detail)
- Research Area endpoints (list, detail)
- Publication & Opportunity endpoints
- Search suggestions endpoint

## Day 3: Auth + Application Tracker
- User registration & login (JWT)
- Auth middleware
- Application CRUD (add, update, remove, list)
- Status pipeline (interested → applied → interview → accepted/rejected)

## Day 4: Frontend Core
- React + Vite setup with Tailwind
- Routing (React Router)
- Navbar + Footer
- Landing page
- Discover page with filters
- Professor profile page

## Day 5: Frontend Features + Polish
- Auth pages (Login, Register)
- Application Tracker (Saved page)
- Dark mode toggle
- Search command palette (Ctrl+K)
- Final styling + disclaimer
